# Nirbija

a mixer you play.

a row of channels.
plugins live in the strip.
press play.

**linux · pipewire · jack · clap · lv2 · vst3**

---

## what it is

a mixer. plugins sit in the strip. you play, loop, record. there is no timeline.

| | |
|---|---|
| 01 host | clap, lv2, vst3. native editors, same slot. |
| 02 mixer | inserts, sends, buses. one strip per voice. |
| 03 loop | quantised. play against yourself. |
| 04 record | armed channels and the master. |
| 05 midi | jack ports, learn, keys on the strip. |
| 06 session | the graph and the plugin state. |

## does

- host the plugins you already have
- mix, send, loop, record
- talk to pipewire and jack
- keep a session

## does not

- arrange clips on a timeline
- replace a daw
- come with sounds
- run on windows or macos

## requires

- a linux desktop
- pipewire or jack
- the plugins you already own
